Simple and clean contact rotator. Adds a floating icon to distribute incoming messages across agents based on their active schedule.

== Description ==

Agent Rotator for WhatsApp Premium is an advanced tool that allows you to manage incoming prospect queries and distribute them seamlessly among your active sales or support agents through WhatsApp.

Unlike the free Lite edition (limited to 2 agents), the Premium version supports **unlimited agents**, a configurable floating bubble with animated pulse, and a Guard Agent for out-of-hours fallback.

### Premium Features
* **Unlimited agents** — no restrictions
* Customizable floating bubble text (editable from the WP dashboard)
* Pulse animation on the floating button to draw attention
* Shift assignments based on days and hours per agent
* **Guard Agent** — out-of-hours fallback to a designated contact
* Global pre-filled WhatsApp message
* Inline JS field validation with visual error tooltips
* Secure input sanitization and output escaping

== Installation ==

1. Upload the plugin folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Access the 'WA Agent Rotator' menu in your WordPress dashboard.
4. Set up your agents and customize your floating widget.
5. Optionally configure a Guard Agent for out-of-hours coverage.
